About

Sentinel-X watches this machine through four collectors: processes, files, USB drives and Windows logons. Every observation is stored in one event format, grouped into time-based clusters, scored, and tagged with MITRE ATT&CK techniques where that is defensible.

This page reads the local database and nothing else. The server listens on 127.0.0.1 only, serves a fixed set of routes, and builds this page with textContent so event text can never run as code.
